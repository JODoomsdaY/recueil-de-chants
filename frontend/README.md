# Frontend Angular — Recueil de chants

```bash
npm install
npm start                    # http://localhost:4200 (proxy /api → http://localhost:8080)
npx ng test --watch=false    # tests unitaires (Vitest)
npx ng build                 # build de production dans dist/
```

Voir le [README principal](../README.md) pour l'architecture et l'API.
